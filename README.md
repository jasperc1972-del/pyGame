🚀 飛船射擊遊戲 Space Blaster
這是一款由 Python + Pygame 製作的 2D 太空射擊遊戲，玩家操作飛船在宇宙中穿梭，射擊隕石並累積分數。遊戲融合了動態圖像、音效與碰撞判斷，適合初學者學習遊戲開發，也適合玩家挑戰反應力！
🎮 遊戲特色
• 	🛸 玩家可左右移動飛船並發射子彈(Z鍵)
• 	🪨 隨機生成多種尺寸的旋轉隕石
• 	💥 子彈擊中隕石時播放爆炸音效
• 	🔊 背景音樂與射擊音效完整呈現
• 	📈 分數系統即時顯示

▶️ 執行方式
請先安裝 Pygame：
pip install pygame
然後執行主程式：
python main.py
